# Exact-ratio registry boundary

This directory addition preserves the distinction between exact mathematical value, positional representation, and geometry/provenance metadata.

Canonical arithmetic is unchanged: `77/33 = 7/3`.

Canonical storage may retain both raw and reduced tuples so that scale/count/provenance is not silently erased.

Any linkage to an existing RLL formula ID must be established by repository evidence; unmatched links remain `TOKEN_VAZIO`.
