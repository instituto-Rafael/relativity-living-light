## 10. Scientific value

The strongest immediate application is not to add freedom to the cosmology, but to **remove redundant geometry features and expose the two independent BAO directions**: scale and anisotropy.

A second application is trajectory geometry in G1 event chains: curvature/torsion can provide a compact geometric signature of motion before the physical scenario classifier is evaluated.

A third application is covariance geometry in G6, which gives a natural bridge from the project’s ellipse/projection work to statistically valid uncertainty handling.
