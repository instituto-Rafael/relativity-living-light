## 1. Boundary

This extension accepts the new session material only as measurable state -> typed transport/energetic model -> falsifiable behavioral/metabolic observable.

It does not turn sulbutiamine, vitamins, minerals, fatty acids or brown fat into cosmological evidence or treatment claims.

## 2. Neuroenergetic action state

x_action(t)=[B1_status,B12_status,Mg_status,ATP_brain,DA_effort,BG_select,motor_cortex,MN_output,fatigue,stress,sleep,reward]

cellular energy != motivation
motivation != action selection
action selection != motor output
motor output != muscle tone

Sulbutiamine/Arcalion is recorded as a synthetic thiamine derivative with a regulatory fatigue/asthenia indication in France and mixed clinical efficacy evidence. Animal cortical dopamine/glutamate findings are MECHANISTIC_PRECLINICAL, not a human will claim.

## 3. Multigradient transport gate

J_v=L_p(DeltaP-sigma*DeltaPi)

J_i = J_i_diff + J_i_electro + J_i_adv

with membrane partition/friction terms where required.

osmosis: osmotic/chemical force drives water
RO: hydraulic pressure drives against osmotic direction
ED: electrical potential drives ion separation
RED: salinity chemical potential drives electrical power

This preserves inverse/reverse process language without confusing the source of free energy.

## 4. EC / KH / pH state vector

x_water=[EC,pH,TA,KH_carbonate,TDS,I_ionic,Na+,Cl-,Ca2+,Mg2+,HCO3-,CO3(2-),T]

EC != pH
pH != alkalinity
carbonate hardness != total alkalinity in all solutions
conductivity != exact ionic strength without composition model

Equalization is represented as relaxation toward lower generalized free-energy gradients, not equality of all observables.

## 5. Brown-adipose thermogenic gate

x_BAT=[NE,betaAR,DIO2,T3_local,UCP1,FFA,glucose,O2,heat,FGF21,NRG4,adiponectin/leptin_context]

cold -> sympathetic NE -> lipolysis/substrate uptake -> mitochondrial proton gradient -> UCP1 uncoupling -> heat + increased substrate oxidation

Human evidence allows:
acute/cold-induced BAT activation -> increased energy expenditure in some studies -> increased glucose/fatty-acid use -> improved insulin sensitivity/glucose disposal in selected experiments

It does not allow:
BAT -> universal permanent reversal of insulin resistance

## 6. Micronutrient/lipid gate

Magnesium:
Mg -> ATP-enzyme / signaling cofactor context
deficiency status -> effect modifier
supplementation -> heterogeneous RCT effects

B12:
methylmalonyl-CoA -> succinyl-CoA
homocysteine -> methionine
B12 = deficiency-sensitive neuro-metabolic variable, not generic stimulant.

Fatty acids:
omega-3/EPA-DHA -> membrane/mediator pools -> possible stress-response modulation
omega-6/LA -> essential membrane/oxylipin precursor -> context-dependent metabolic effects
omega-9/oleate -> MUFA membrane/fuel pool -> dietary substitution context

The RLL gate rejects:
omega3:omega6 ratio -> universal insulin-sensitivity controller

## 9. Falsifiable hypotheses

RLL-NAE-H1 — neuroenergetic sufficiency versus motivation
Correcting a proven B1/B12/Mg deficiency can improve energy/neurological capacity, but does not necessarily alter effort-based decision making after controlling reward/sleep/stress.

RLL-NAE-H2 — sulbutiamine effort bridge
Sulbutiamine changes a preregistered effort/vigor endpoint in humans independently of placebo and fatigue reduction.
Current state: TOKEN_VAZIO_CAUSAL.

RLL-NAE-H3 — multigradient equalization
A typed pressure+osmotic+electrical+acid-base model predicts transport better than a single undifferentiated potential.
Falsifier: collapsed scalar matches or outperforms typed model outside sample.

RLL-NAE-H4 — BAT metabolic gate
Cold-induced BAT activity predicts incremental glucose disposal/REE after controlling shivering, body composition and sympathetic markers.
Falsifier: BAT activity adds no incremental prediction.

RLL-NAE-H5 — micronutrient baseline interaction
Baseline deficiency/status modifies Mg/B12 intervention response more strongly than nominal supplement exposure alone.

RLL-NAE-H6 — fatty-acid substitution
Replacing saturated-fat exposure with a defined MUFA/PUFA composition predicts metabolic response better than an omega-3/omega-6 ratio alone.
