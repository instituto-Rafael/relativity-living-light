# RLL Canonical Region — Freestanding C V1

**State:** IMPLEMENTED / claim_allowed=false / fail-closed  
**Scope:** canonical coupling of the committed real RLL cosmology inputs and validated local-physics adapters.

## What this closes

The existing `pantheon_freestanding.c` provides low-level fixed-point, FNV-1a, CRC32 and syscall primitives. It did not define the contract that joins:

```text
observation
→ observable identity
→ unit
→ uncertainty
→ real/synthetic boundary
→ source SHA-256
→ model-ready canonical state
→ claim boundary
→ deterministic receipt
```

`rll_canonical_region.c` is that contract. It is a streaming layer; it does not allocate or retain the full datasets.

| Block | File | Canonical rows |

Every file is pinned to the SHA-256 already registered in
`data/real/cosmology/real_source_signatures.json`. A missing or zero digest,
synthetic flag, non-positive uncertainty, unsupported observable, malformed
schema, or non-blocked claim fails closed.

## Freestanding boundary

The production module uses:

- no `stdlib.h`, `stdio.h`, `string.h`, `stdint.h` or `math.h`;
- no heap, `malloc`, GC, file I/O, floating point or locale;
- Q32.32 decimal conversion, including scientific notation used by CMB covariance;
- fixed structs and streaming parsing;
- no unresolved external symbols in the compiled object on the CI host;
- FNV-1a/CRC32 rolling execution receipt plus externally pinned SHA-256 provenance.

The hosted runner in `tests/canonical_region_host_runner.c` uses libc only to
open the repository files. It is a test adapter, not part of the freestanding
runtime.

## Claim boundary

`rllc_finalize()` returns:

- `RLLC_OK` only when H(z), BAO, fσ8 and CMB are present, valid and the CMB
  covariance is present;
- `RLLC_TOKEN_VAZIO` when a required block is absent;
- a negative fail-closed error when a structural/provenance boundary is broken.

The receipt always writes `claim_allowed=0`. `RLLC_OK` means **canonical inputs
are structurally model-ready**. It does not mean RLL is scientifically
preferred, confirmed, or superior to ΛCDM/CPL.

## Local physical adapter bridge

`rllc_ingest_local_adapter_scalar()` accepts already validated physical scalar
records from geophysical/sensor adapters. Such records are forced to
`LOCAL_CONTEXT_ONLY`, require non-zero SHA-256 provenance and cannot satisfy the
four cosmology dataset gates. This preserves the existing rule that local
geophysical evidence is not promoted into cosmological evidence.

## Build and verification

```bash
gcc -std=c11 -Wall -Wextra -Werror -pedantic \
  -ffreestanding -fno-builtin -fno-stack-protector \
  -fno-asynchronous-unwind-tables -nostdlib -c \
  core/lowlevel_runtime/c/rll_canonical_region.c \
  -Icore/lowlevel_runtime/include \
  -o /tmp/rll_canonical_region.o

nm -u /tmp/rll_canonical_region.o
pytest -q tests/test_rll_canonical_region_freestanding.py
```

Expected hosted receipt for the committed data:

```text
RLL_CANONICAL_REGION_V1 PASS accepted=65 hz=33 bao=13 fs8=16 cmb=3 ... claim_allowed=0
```

## Invariants

1. Absence is `TOKEN_VAZIO`, never numeric zero.
2. Source registration is not scientific validation.
3. All accepted measurements carry a positive uncertainty.
4. Synthetic data cannot cross the canonical real-data gate.
5. Local physical adapters remain context-only unless a separate, explicit
   scientific contract promotes them.
6. No result generated by this layer authorizes a superiority claim.
